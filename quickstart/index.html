Overview

Domma is a lightweight, zero-dependency JavaScript framework.

Features

  • jQuery-compatible DOM API
  • Lodash-style utilities
  • Moment-style dates
  • Reactive models with pub/sub
  • UI components
  • DataTable-like tables

Usage

// Include Domma
<script src="js/domma.min.js"></script>

// Use the short aliases
$('#element').addClass('active');
const data = _.groupBy(items, 'category');
const date = D().format('YYYY-MM-DD');

Accordion

What is Domma? ▼
Dynamic Object Manipulation & Modeling API — a complete front-end toolkit.
How do I get started? ▼
Include the CSS and JS files, then start using the $, _, D, and M aliases in your code.
What are the short aliases? ▼
  • $ — DOM manipulation (jQuery-style)
  • _ — Utilities (Lodash-style)
  • D — Dates (Moment-style)
  • M — Models (Reactive data)

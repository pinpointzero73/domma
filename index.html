Domma

Dynamic Object Manipulation & Modeling API

A lightweight, zero-dependency JavaScript framework combining jQuery-style DOM manipulation, Lodash utilities, and modern UI components.

1

Zero Dependencies

No external libraries required. Everything is self-contained in a single ~160KB bundle.

<script src="domma.min.js"></script>
// That's it. You're ready to go!
2

jQuery-Style DOM API

Familiar $() syntax with 90+ chainable methods for traversal, manipulation, events, and effects.

$('.card').addClass('active')
  .fadeIn(300)
  .on('click', handler);
3

Template Engine

Mustache-style templates with loops, conditionals, partials, and auto-escaping built in.

const tmpl = _.template('Hello {{name}}!');
tmpl({ name: 'World' }); // "Hello World!"
_.render('{{#each items}}{{.}}{{/each}}', data);
4

Lodash-Compatible Utils

120+ utility functions for arrays, objects, strings, and functions — all via the _ alias.

const grouped = _.groupBy(users, 'role');
const unique = _.uniqBy(items, 'id');
const result = _.flow([fn1, fn2])(data);
5

Moment-Style Dates

Chainable date manipulation with formatting, parsing, comparison, and relative time.

D().add(7, 'days').format('MMM D, YYYY');
D('2025-01-01').fromNow();
D().startOf('month').isBefore(D());
6

Reactive Models

Pub/sub events, schema validation, and two-way DOM binding for reactive data.

const user = M.create({ name: M.types.string });
M.bind(user, 'name', '#input', { twoWay: true });
user.onChange('name', val => console.log(val));
7

UI Components

Ready-to-use modals, tabs, accordions, carousels, tooltips, and toasts.

const modal = Domma.elements.modal('#dialog');
modal.open();
Domma.elements.toast.success('Saved!');
8

DataTable-Like Tables

Sorting, filtering, pagination, row selection, and CSV/JSON export built in.

const table = Domma.tables.create('#grid', {
  data, columns, pagination: true
});
table.search('query').toCSV();
9

Mutable Configuration

Setup once, update anytime. Inspect and reset configuration at runtime.

$.setup({ '#modal': { component: 'modal' } });
$.update('#modal', { options: { backdrop: false } });
$.config('#modal'); $.reset('#modal');
10

100+ SVG Icons

Built-in icon library with render, inject, and scan modes. Customisable size and colour.

Domma.icons.render('search', { size: 24 });
Domma.icons.inject('#icon-container', 'check');
<i data-icon="heart"></i> // Auto-scanned
11

Theme System

Light/dark modes with 8 colour variants. Auto-detects system preference and persists choices.

Domma.theme.init({ autoDetect: true });
Domma.theme.set('dark');
Domma.theme.setVariant('ocean');

# Christmas Icons

**Nine new festive icons** in the Seasonal set, for an advent calendar, a Christmas quiz or a
crossword and the rest of December: `christmas-quiz` (a bauble with a question mark),
`christmas-crossword` (a grid with a sprig of holly), `cracker`, `stocking`, `santa-hat`,
`christmas-pudding`, `gingerbread-man`, `advent-calendar` (one door open) and `candle`.

🎄 **Drawn like the rest of the set**

*   Same rules as the existing Seasonal icons (`tree`, `bauble`, `holly`, `snowman` ...): a 24px
    grid, round 1.5px strokes, no fill, so they take the colour of the text around them and sit
    beside the others at any size.

*   They join the Seasonal category in `I.listCategories()` and the icon showcase; no names
    clash with the existing set (541 -> 550). A test checks each one is registered, listed and
    renders.

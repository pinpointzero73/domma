# Admin Atelier

Admin Atelier adds a warm corporate palette in light and dark modes. Ivory and stone surfaces pair with ink-blue actions in light mode; warm graphite and softened blue define dark mode. Bronze accents, restrained corners and subtle shadows keep the interface calm and structured.

- Register `admin-atelier-light` and `admin-atelier-dark` in the Domma theme engine and Theme Roller.
- Generate both variants from the shared admin component token contract and include them in distributed theme CSS.
- Validate text, muted labels, buttons, sidebar and tooltip contrast in both modes.

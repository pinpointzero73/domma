Remember expanded menus across page reloads

Persistent State

Expand some menus, then reload the page. The expanded state will be remembered!

JavaScript


            Domma.elements.sidebar('#sidebar-persist', {
            contentSelector: '#demo-content-persist',
            persistExpanded: true,
            persistKey: 'my-app-sidebar',  // Unique key for this sidebar
            items: [/* ... */]
            });

Switch between light and dark themes

Light Sidebar Theme

The sidebar component adapts to light or dark theme variants. Use variant: 'theme' to follow the active theme instead.

JavaScript


            Domma.elements.sidebar('#sidebar-light', {
            contentSelector: '#demo-content-light',
            variant: 'light',  // or 'dark', or 'theme' to follow the active theme
            items: [/* ... */]
            });

Fixed (stays at top of viewport):


            Domma.elements.navbar('#nav', {
            position: 'fixed',  // Always at top of viewport
            brand: { text: 'App' },
            items: [...]
            });

Sticky (scrolls normally until reaching top):


            Domma.elements.navbar('#nav', {
            position: 'sticky',  // Sticks when scrolled to top
            brand: { text: 'App' },
            items: [...]
            });

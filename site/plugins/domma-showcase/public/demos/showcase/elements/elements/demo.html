Structural components for building interfaces

Accordion

Collapsible content sections with smooth animations.

  • Single or multi-expand
  • Smooth animations
  • Nested support
  • Keyboard accessible
elements.accordion('#faq', { multiExpand: false })

Avatar

A person's picture, initials or an icon - alone or stacked in a group.

  • Initials and a stable colour from the name
  • Picture with initials fallback
  • Sizes, shapes, status dot and ring
  • Groups with "+N" and a popover
E.avatarGroup('#team', { people, max: 4 })

Badge

  • Counter badges
elements.badge('#el', { variant: 'primary' })

  • Pulse animation
elements.numberBadge('#btn', { count: 5 })

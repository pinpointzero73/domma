Using Generated Blueprints

// 1. Build your blueprint in Schema Builder // 2. Export as JavaScript const contactBlueprint = { name: { type: 'string', required: true, label: 'Full Name' }, email: { type: 'email', required: true, label: 'Email Address' }, message: { type: 'textarea', required: true, label: 'Message' } }; // 3. Use with Domma.forms to generate a form const form = Domma.forms.create('#contact-form', { blueprint: contactBlueprint, layout: 'stacked', submitText: 'Send Message', onSubmit: async (data) => { console.log('Form data:', data); await Domma.http.post('/api/contact', data); } }); // 4. Or use with Domma.models for reactive data const model = M.create(contactBlueprint, { name: '', email: '', message: '' }); // 5. Or use with CRUD helper for complete data management Domma.forms.crud('#crud-container', { blueprint: contactBlueprint, endpoint: '/api/contacts', title: 'Contacts' });

About Domma
A lightweight, zero-dependency JavaScript framework built with simplicity and developer experience in mind.

Our Mission

Domma was created to provide developers with a powerful yet lightweight alternative to heavy JavaScript frameworks. We believe that building modern web applications shouldn't require megabytes of dependencies or complex build processes.

Our goal is to combine the best parts of familiar libraries like jQuery, Lodash, and Moment.js into a single, cohesive package that's easy to learn and a joy to use.

Our Values

Simplicity

Clean APIs that are intuitive and easy to learn. No unnecessary complexity.

Lightweight

Zero external dependencies. One script tag and you're ready to build.

Developer Experience

Familiar syntax patterns that let you be productive from day one.

Flexibility

Use it with your existing CSS framework or go completely headless.

The Team

Domma is developed and maintained by DCBW-IT, a team passionate about creating tools that make web development rapid, accessible, and enjoyable.
We're committed to keeping Domma stable, well-documented, and continuously improving based on community feedback.

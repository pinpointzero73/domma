Input Addons

An addon is an icon or a little text joined to the start or end of a field - a magnifier on a search box, "£" on a price, "kg" on a weight. The addon and the field share one border and one rounded outline, so they read as a single control: the focus ring goes round the whole group, and the addon takes the focus and error colours along with the field. Each addon is as wide as what it holds, so "£" and "https://" both fit.

In a Forma blueprint set formConfig.prefix and/or formConfig.suffix. It works on single-line inputs, selects and textareas. For an input that is already on the page, use E.inputGroup() - it writes exactly the same markup.

What a slot can be

ValueRendersWhere
{icon: 'search'}A Domma icon (a plain icon name only)Forma and E.inputGroup
{text: '£'}Text, set as text - never parsed as HTMLForma and E.inputGroup
'kg'Shorthand for {text: 'kg'}Forma and E.inputGroup
{html: '<kbd>K</kbd>'}Raw HTML - you are responsible for what goes inForma only

Addons are decoration: clicks pass straight through to the field, and they are hidden from screen readers, so the field's label should still say what it is for.

Interactive extras

Four extras are real controls joined to the field in the same style - buttons you can click and tab to, each with an accessible name. The keys are the same in a blueprint's formConfig and in E.inputGroup()'s options, and they sit happily inside a prefix or suffix.

KeyAddsApplies to
reveal: trueAn eye button that shows and hides the passwordPassword inputs
clear: trueAn × that appears once there is a value and empties the fieldText-like inputs and textareas
stepper: true− and + buttons that honour min, max and stepNumber inputs
counter: true | 200"12 / 200" under the field, updated as you typeText-like inputs and textareas

Icon prefix - search field


search: {
    type: 'text',
    label: 'Search',
    formConfig: {prefix: {icon: 'search'}, placeholder: 'Type to search...'}
}

Text prefix and suffix - price field


price: {
    type: 'number',
    label: 'Price',
    formConfig: {
        prefix: {text: '£'},
        suffix: {text: '.00'}
    }
}

Units and schemes

The addon grows to fit its text, so a unit or a URL scheme sits beside the value without covering it. 


weight: {
    type: 'number',
    label: 'Parcel weight',
    formConfig: {suffix: {text: 'kg'}}
},
website: {
    type: 'string',
    label: 'Website',
    formConfig: {prefix: {text: 'https://'}, placeholder: 'example.com'}
}

String shorthand

A plain string is shorthand for {text: ...}. 


salary: {
    type: 'number',
    label: 'Salary',
    formConfig: {prefix: '£', suffix: 'a year'}
}

A select with an icon prefix


country: {
    type: 'select',
    label: 'Country',
    options: [
        {value: 'gb', label: 'United Kingdom'},
        {value: 'ie', label: 'Ireland'},
        {value: 'fr', label: 'France'}
    ],
    formConfig: {prefix: {icon: 'globe'}}
}

A textarea with a suffix


message: {
    type: 'textarea',
    label: 'Message',
    formConfig: {rows: 4, suffix: {icon: 'message-square'}}
}

HTML suffix - keyboard hint


query: {
    type: 'text',
    label: 'Quick search',
    formConfig: {
        prefix: {icon: 'search'},

E.inputGroup - on an input already on the page

The field below is a plain <input class="form-input"> in this page's HTML. E.inputGroup() wraps it and joins the addons. The buttons change them with update(), take them away with destroy(), and bind the input again.

Current markup:



            

                

let group = E.inputGroup('#ig-demo', {prefix: '£', suffix: '.00'});

$('#ig-icon').on('click', () => group.update({prefix: {icon: 'tag'}}));
$('#ig-kg').on('click', () => group.update({suffix: 'kg'}));
$('#ig-no-suffix').on('click', () => group.update({suffix: null}));
$('#ig-destroy').on('click', () => group.destroy());


            

        

    


    

        
Show / hide password

        

            

                reveal: true adds an eye button that switches the field between hidden and plain
                text. It is a toggle button (aria-pressed), so a screen reader hears "Show password,
                toggle button, pressed". Clicking it leaves the caret in the field.
            

            

            

                

password: {
    type: 'password',
    label: 'Password',
    formConfig: {prefix: {icon: 'lock'}, reveal: true}
}


            

        

    


    

        
Clear button

        

            

                clear: true adds an × that shows only while the field has a value. Clicking it
                empties the field, fires input and change - so the form's model and any
                listener of your own see the change - and puts the focus back in the field. Here it sits beside an
                icon prefix; the last value the model saw is shown underneath.
            

            

            
Model value: ""

            

                

search: {
    type: 'string',
    label: 'Search',
    formConfig: {prefix: {icon: 'search'}, clear: true, placeholder: 'Type, then clear'}
}


            

        

    


    

        
Number stepper

        

            

                stepper: true puts − and + either side of a number field. They step by the
                field's step, stop at min and max (the button at a limit is
                disabled), and fire input and change on every step. Hold a button down to
                keep stepping. Addons still go outside, as with the "£" and "per night" here.
            

            

            

                

guests: {
    type: 'integer',
    label: 'Guests',
    min: 1,
    max: 8,
    formConfig: {stepper: true}
},
rate: {
    type: 'number',
    label: 'Nightly rate',
    min: 0,
    max: 500,
    step: 12.5,
    formConfig: {prefix: '£', suffix: 'per night', stepper: true}
}


            

        

    


    

        
Character counter

        

            

                counter: true shows "12 / 200" under the field, using the field's
                maxLength; a number (counter: 60) sets the limit itself. It updates as you
                type, is announced politely to screen readers and is linked to the field with
                aria-describedby. It turns amber from 90% of the limit, and red if an explicit limit is
                passed.
            

            

            

                

headline: {
    type: 'string',
    label: 'Headline',
    formConfig: {counter: 60, clear: true}
},
bio: {
    type: 'textarea',
    label: 'Short bio',
    maxLength: 200,
    formConfig: {rows: 3, counter: true}
}

Tutorial - joining an addon to your own input

        

            
Step 1 - Write the input as usual

            

                No wrapper markup needed. Give the input the usual form-input (or
                form-select) class and a label.
            

            

                

<label class="form-label" for="weight">Parcel weight</label>
<input id="weight" class="form-input" type="number">


            


            
Step 2 - Join the addons

            

                E.inputGroup(selector, {prefix, suffix}) wraps the input in a
                .input-group-icon group and adds the addons. Each slot takes the same values as
                formConfig.prefix: an icon, text, or a string.
            

            

                

const weight = E.inputGroup('#weight', {suffix: 'kg'});


            


            
Step 3 - Change or remove them later

            

                update() changes either slot and leaves the other alone; null removes
                one. destroy() removes the addons and, if E.inputGroup made the wrapper,
                the wrapper too, leaving the input where it was.
            

            

                

$('#units').on('change', (e) => {
    weight.update({suffix: e.target.value === 'metric' ? 'kg' : 'lb'});
});

weight.update({prefix: {icon: 'package'}});   // add a prefix, keep the suffix
weight.update({prefix: null});                // and take it off again
weight.destroy();                             // back to a plain input


            

            

                Binding an input that Forma already rendered with addons reuses Forma's group, so
                E.inputGroup() is also the way to change a blueprint field's addons after it is on
                screen.
            


            
Step 4 - Add the extras

            

                Pass reveal, clear, stepper or counter alongside
                (or instead of) the addons. An extra the input cannot take is skipped - reveal needs a
                password, stepper a number - so a shared options object is safe.
            

            

                

const qty = E.inputGroup('#qty', {stepper: true, suffix: 'boxes'});
const note = E.inputGroup('#note', {counter: 120, clear: true});

qty.step(1);                       // step from code, as the + button does
note.update({clear: false});       // extras come and go through update() too


            


            
Step 5 - Set values from code

            

                The extras follow the field's input and change events and a form reset. If
                you set value from code without firing an event, call refresh() so the
                clear button, the stepper limits and the counter catch up.
            

            

                

$('#note').val('Leave with the neighbour at number 12');
note.refresh();


            

            

                In a blueprint, Forma binds the extras after it renders and removes them again on a re-render or
                form.destroy(); a formConfig.labels object renames the buttons (for another
                language, say).
            

        

    


    

        
Options and methods

        

            

                
Option / methodDescription

                
                    
prefixSlot at the start: {icon}, {text} or a string. Default null

                    
suffixSlot at the end, same values. Default null

                    
revealtrue: show / hide button on a password input. Default false

                    
cleartrue: clear button, shown while there is a value. Default false

                    
steppertrue: − / + buttons on a number input. Default false

                    
countertrue (limit from maxLength) or a number. Default false

                    
labelsButton names: {reveal: 'Show password', clear: 'Clear', decrease: 'Decrease', increase: 'Increase'}

                    
update({...})Change any of the above; null removes an addon, false an extra, leaving a key out keeps it. Returns the instance

                    
refresh()Re-read the value after setting it from code: clear button, stepper limits, counter

                    
step(dir)Step a stepper field by one step, 1 up or -1 down

                    
destroy()Remove the addons and extras (and their listeners), and the wrapper if this instance made it

                    
input / wrapper / extrasThe bound input, its .input-group-icon group, and the extras' elements (reveal, clear, decrease, increase, counter)

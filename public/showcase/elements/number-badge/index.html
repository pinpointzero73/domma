Number Badge
Notification counters and status dots — CSS-only standalone variants, a JavaScript API for live counters, and a declarative Web Component

Number Badge

Number Badges are small circular counters or dot indicators that sit on top of another element — typically an icon or button — to communicate an unread count or live status. Unlike the general-purpose Badge component (which labels text), Number Badge is purpose-built for notification counters and presence indicators.

Key Features

  • CSS-Only Standalone — .badge-number and .badge-dot with eight colour variants, no JavaScript needed
  • CSS Counter Positioning — .badge-counter-wrapper + .badge-counter for manually positioned overlapping counters
  • JavaScript API — E.numberBadge(selector, options) wraps any element in a live counter with increment/decrement/pulse controls
  • Web Component — <domma-number-badge> for clean, declarative markup
  • Auto-Hide — Counter hides automatically when count reaches zero
  • Pulse Animation — Built-in badge-pulse animation for urgent indicators
  • Accessibility — Counter element carries aria-live="polite" and role="status"

Quick Start — Three Approaches

1. CSS-only standalone badge — no wrapper needed


<!-- Circular counter -->
<span class="badge-number badge-number-danger">5</span>

<!-- Dot indicator -->
<span class="badge-dot badge-dot-success"></span>

<!-- Positioned counter on an icon -->
<span class="badge-counter-wrapper">
    <button class="btn btn-secondary">
        <span data-icon="bell"></span>
    </button>
    <span class="badge-counter badge-counter-danger">3</span>
</span>

2. JavaScript API — live, interactive counter


const badge = E.numberBadge('#my-button', { count: 5, variant: 'danger' });

badge.increment();       // 6
badge.decrement();       // 5
badge.setCount(0);       // hides automatically
badge.setDot(true);      // switch to dot mode
badge.setPulse(true);    // add pulse animation
badge.setVariant('info');
badge.getCount();        // → 0
badge.destroy();

3. Web Component — declarative markup


<domma-number-badge count="3" variant="danger">
    <button class="btn btn-secondary">
        <span data-icon="bell"></span> Notifications
    </button>
</domma-number-badge>

JavaScript API

E.numberBadge(selector, options) wraps an existing element in a <domma-number-badge> Web Component and returns a control object with a fluent API. The original element is preserved as the slotted child.

Basic Counter — Bell Notifications

bell notifications
mail count 

const bellBadge = E.numberBadge('#bell-btn', { count: 5, variant: 'danger' });
const mailBadge = E.numberBadge('#mail-btn', { count: 3, variant: 'primary' });

$('#bell-inc').on('click', () => bellBadge.increment());
$('#bell-dec').on('click', () => bellBadge.decrement());

// Count reaches 0 → badge hides automatically
$('#bell-reset').on('click', () => bellBadge.setCount(0));

$('#mail-inc').on('click', () => mailBadge.increment());
$('#mail-dec').on('click', () => mailBadge.decrement());

Toggle Dot Mode

Switch between a numeric counter and a simple dot indicator at runtime.

online status 

let isDot = false;
let isPulse = false;
const dotBadge = E.numberBadge('#user-btn', { count: 2, variant: 'success' });

$('#toggle-dot').on('click', () => {
    isDot = !isDot;
    dotBadge.setDot(isDot);
});

$('#toggle-pulse').on('click', () => {
    isPulse = !isPulse;
    dotBadge.setPulse(isPulse);
});

Variant Switcher

variant: danger 

const variantBadge = E.numberBadge('#star-btn', { count: 7, variant: 'danger' });

$('.variant-btn').on('click', function () {
    const v = $(this).data('variant');
    variantBadge.setVariant(v);
});
Auto-hide: When setCount(0) is called (or decrement reaches zero), the counter element hides automatically. It reappears the moment the count goes above zero again. Dot mode is never hidden regardless of count.

Programmatic Control of Web Component

Access the element directly and call its API methods.


const badge = $('domma-number-badge')[0];

// All methods return `this` for chaining
badge.setCount(10);
badge.increment(3);   // → 13
badge.decrement();    // → 12
badge.setVariant('primary');
badge.setDot(true);
badge.setPulse(true);
badge.getCount();     // → 12 (dot mode preserves stored count)

Accessibility

Screen Reader Behaviour

When using the JavaScript API or Web Component, the internal counter element is rendered with:

  • aria-live="polite" — announces count changes to screen readers without interrupting the current reading flow
  • role="status" — identifies the element as a live status region

This means that when badge.increment() or setCount() is called, assistive technologies will announce the updated value to the user without requiring focus on the badge.

CSS-Only Considerations

When using the CSS-only .badge-counter approach you are responsible for adding ARIA attributes manually. Pair the counter with a visually hidden label or add aria-label to the parent button: 


<!-- Describe count in the button's accessible name -->
<span class="badge-counter-wrapper">
    <button class="btn btn-ghost" aria-label="Notifications, 4 unread">
        <span data-icon="bell" aria-hidden="true"></span>
    </button>
    <span class="badge-counter badge-counter-danger" aria-hidden="true">4</span>
</span>

<!-- OR use aria-live on the counter itself -->
<span class="badge-counter badge-counter-danger"
      aria-live="polite"
      role="status">4</span>
Tip: For pulse animations, consider @media (prefers-reduced-motion: reduce) in your custom styles to disable the animation for users who prefer reduced motion. Domma's Web Component respects this automatically.

API Reference

Factory


const badge = E.numberBadge(selector, options);

// options:
// {
//   count:       number   — initial count (default: 0)
//   variant:     string   — colour variant (default: 'danger')
//   dot:         boolean  — dot mode, hides count (default: false)
//   pulse:       boolean  — pulse glow animation (default: false)
//   borderColor: string   — custom border colour (default: null)
// }

Instance Methods

Method Parameters Returns Description
setCount(count) number this Set the counter to an exact value. Hides badge if count is 0 (not in dot mode).
increment(by) number (default: 1) this Increase the count by by.
decrement(by) number (default: 1) this Decrease the count by by. Will not go below zero.
setDot(dot) boolean this Toggle dot mode. When true, hides the counter text and shows a small dot.
setVariant(variant) string this Change the colour variant. Accepts: primary, secondary, success, danger, warning, info, light, dark.
setPulse(pulse) boolean this Enable or disable the pulsing glow animation.
getCount() — number Return the current count value.
remove() — void Remove the badge wrapper from the DOM, restoring the original element in place.
destroy() — void Destroy the Web Component and clean up all resources.

Web Component Attributes

Attribute Type Default Description
count number 0 The numeric counter value.
variant string danger Colour variant: primary, secondary, success, danger, warning, info, light, dark.
dot boolean (presence) — When present, renders a dot instead of a counter.
pulse boolean (presence) — When present, applies the pulsing glow animation.
border-color string (CSS colour) var(--dm-background) Custom border colour for the counter ring. Useful when the background behind the badge is not the page background.

CSS Classes Reference

Class Purpose
.badge-number Standalone circular counter badge. Expands to pill for multi-digit numbers.
.badge-number-{variant} Colour modifier for .badge-number. Variants: primary, secondary, success, danger, warning, info, light, dark.
.badge-dot Small solid circle for presence and status indicators.
.badge-dot-{variant} Colour modifier for .badge-dot. Same eight variants as above.
.badge-counter-wrapper Positioning context for an overlapping counter. Set on the parent element containing the target and the badge.
.badge-counter The overlapping counter pill that sits in the top-right corner of its wrapper. Requires .badge-counter-wrapper on the parent.
.badge-counter-{variant} Colour modifier for .badge-counter. Same eight variants.
.badge-counter-hidden Hides the counter with display: none !important. Applied automatically when count is zero by the JS API.
.badge-pulse Applies a pulsing glow animation to .badge-counter. Can be combined with any variant.

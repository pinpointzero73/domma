Quickstart

Get up and running with Domma in minutes. See how simple it is to create interactive components with declarative configuration.

Zero Dependencies Single Include Declarative Config

1. Include Domma

Add the CSS and JS files to your page

That's all you need:

  • domma.css - Styles & components
  • domma-themes.css - Theme system (optional)
  • domma.min.js - JavaScript (~250KB)
<!-- CSS -->
<link rel="stylesheet" href="domma.css">
<link rel="stylesheet" href="domma-themes.css">

<!-- JavaScript -->
<script src="domma.min.js"></script>

2. Cards with Config Engine

Use $.setup() to declaratively configure components

DOM ($)

jQuery-style manipulation

Utils (_)

Lodash-compatible utilities

Click a card...
$.setup({
    '.feature-card': {
        component: 'card',
        options: {
            hover: true,
            clickable: true
        },
        events: {
            click: (e, $el) => {
                const title = $el.find('.card-title').text();
                console.log('Clicked:', title);
            }
        }
    }
});

3. Modal Dialog

Configure modals with backdrop, keyboard support, and callbacks

Example Modal

This modal was configured with $.setup(). Close with X, backdrop click, or Escape key.

$.setup({
    '#demo-modal': {
        component: 'modal',
        options: {
            backdrop: true,
            keyboard: true,
            onOpen: () => console.log('Opened!'),
            onClose: () => console.log('Closed!')
        }
    }
});

// Open programmatically
$.config('#demo-modal').instance.open();

jQuery-compatible DOM, Lodash utilities, Moment-style dates, reactive models.

        options: {

7. DOM Manipulation ($)

jQuery-compatible API with 90+ chainable methods

Click the buttons to manipulate this box 
// Toggle a class
$('#box').toggleClass('active');

// Fade effects
$('#box').fadeToggle(300);

// Change content
$('#box').text('New text!');

// Chain methods
$('.card')
    .addClass('active')
    .css({ opacity: 1 })
    .fadeIn(300);

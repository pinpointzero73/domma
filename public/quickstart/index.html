How It Works

1

Create Your Project

$ mkdir my-app && cd my-app
$ npm init -y

What happens: Creates a new directory and initializes npm package.json

2

Install Domma

$ npm install domma-js

What happens: Downloads Domma (~260KB minified) with zero dependencies

3

Initialize Your Site ⚡ 5 seconds

$ npx domma init

What happens: Creates complete project structure with 5 working pages

Just Want to Try It?

Skip npm and use Domma from a CDN - single HTML file, no build tools.

Copy-Paste Ready:

<!DOCTYPE html>
<html lang="en">
<head>
  <link rel="stylesheet" href="https://unpkg.com/domma-js/public/dist/domma.css">
  <link rel="stylesheet" href="https://unpkg.com/domma-js/public/dist/elements.css">
</head>
<body class="dm-theme-charcoal-dark">
  <nav id="nav"></nav>
  <main class="container py-6">
    <h1>Hello Domma!</h1>
    <button class="btn btn-primary" onclick="showToast()">Click Me</button>
  </main>

  <script src="https://unpkg.com/domma-js/public/dist/domma.min.js"></script>
  <script>
    Domma.theme.init({ theme: 'charcoal-dark' });
    Domma.elements.navbar('#nav', {
      brand: { text: 'My App' },
      items: [{ text: 'Home', url: '/' }]
    });
    function showToast() {
      Domma.elements.toast({ message: 'Hello! 🎉', type: 'success' });
    }
  </script>
</body>
</html>

Note: For production, use the npm workflow above for better performance and bundle optimization.

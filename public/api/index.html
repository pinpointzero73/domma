Address Lookup API
UK postcode validation, full address lookups, and property data - all in a single REST API.

Introduction

The Domma Address Lookup API provides comprehensive UK address data across three tiers of detail. Whether you need simple postcode validation or full transaction history for a specific property, a single API endpoint family covers it all.

Data Sources

  • ONS (Office for National Statistics) - Postcode directory with geography fields: coordinates, local authority, constituency, NHS region, urban classification, and more.
  • Land Registry (LR) - Full residential addresses and property transaction history (sold prices, dates, property type).
  • Companies House (CH) - Registered business addresses, company names, and registration numbers.

Service Tiers

Getting Started

1. Get an API Key

Sign in to your Domma account and navigate to Settings → API Keys to create your first key. Free-tier keys are available immediately; premium and property tiers require purchasing a credit pack.

2. Make Your First Request

Look up a postcode using curl:

Shell
curl -X POST https://api.domma.dev/api/address/v1/lookup \
  -H "Authorization: Bearer addr_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"postcode": "SW1A 1AA"}'

3. Inspect the Response

A successful response returns a 200 OK with JSON:

JSON Response
{
  "success": true,
  "postcode": "SW1A 1AA",
  "tier": "free",
  "creditsUsed": 0,
  "data": {
    "postcode": "SW1A 1AA",
    "latitude": 51.50081,
    "longitude": -0.14145,
    "region": "London",
    "localAuthority": "Westminster",
    "constituency": "Cities of London and Westminster"
  }
}
Tip: The free tier requires no credits and is ideal for integrating postcode validation into forms before committing to a premium lookup.

Authentication

All API requests must be authenticated. The API supports two authentication methods depending on your use case.

API Key (B2B / Server-side)

Pass your API key as a Bearer token in the Authorization header. API keys are in the format addr_xxxxxxxxxxxxxxxxxx.

HTTP Header
Authorization: Bearer addr_xxxxxxxxxxxxxxxxxx

Session Cookie (Web UI)

Authenticated users accessing the API through the Domma web interface use JWT session cookies. These are set automatically on login and do not require manual configuration.

Authentication Errors

StatusCodeMeaning
401 MISSING_AUTH No Authorization header or session cookie provided
401 INVALID_KEY API key is malformed, expired, or has been revoked
403 PERMISSION_DENIED Key exists but lacks the required permission for this endpoint
403 INSUFFICIENT_CREDITS Account has insufficient credits for the requested tier
Keep your API key secret. Never expose it in client-side JavaScript, public repositories, or build artefacts. Use environment variables or a secrets manager.

Base URL

All endpoints are relative to the following base URL:

https://api.domma.dev/api/address

All requests must be made over HTTPS. HTTP requests will be rejected.

API Versioning

Endpoints are versioned via the URL path (e.g. /v1/lookup). Breaking changes are introduced only in new major versions. The current stable version is v1.

Postcode Sold Prices 3 credits

POST /v1/property/postcode All sales within a postcode

Returns all recorded sales for every address within a postcode area.

FieldTypeRequiredDescription
postcode string Required UK postcode to retrieve all property sales for.
limit number Optional Maximum number of transactions to return. Defaults to 50, max 500.

Comparable Sales 3 credits

POST /v1/property/comparables Similar recent sales nearby

Returns comparable sold prices for similar properties in the same area. Useful for estate agents and mortgage applications.

FieldTypeRequiredDescription
postcode string Required Target postcode for comparables search.
propertyType string Optional Filter by type: "detached", "semi-detached", "terraced", "flat", "other".
months number Optional How far back to search. Defaults to 12 months, max 60.
radius string Optional Search radius: "postcode" (default), "sector", or "district".

Rate Limits

Rate limits are applied per API key and per user account. They prevent abuse and ensure fair usage across all customers.

Default Limits

ScopeDefault LimitConfigurable?
Requests per minute (per key) 60 Yes - via PATCH /keys/:id
Requests per day (per key) 10,000 Yes - via PATCH /keys/:id
Bulk lookup batch size 100 postcodes No

Rate Limit Headers

Every API response includes the following headers:

X-RateLimit-Limit: 60
X-RateLimit-Remaining: 57
X-RateLimit-Reset: 1740309660

429 - Too Many Requests

{
  "success": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "You have exceeded the rate limit of 60 requests per minute.",
    "retryAfter": 43
  }
}

Back off and retry after retryAfter seconds, or check the X-RateLimit-Reset header for the exact Unix timestamp when the window resets.

JavaScript (Browser / Node.js fetch) 

const API_KEY = 'addr_your_key_here';
const BASE_URL = 'https://api.domma.dev/api/address';

async function lookupPostcode(postcode, tier = 'free') {
    const response = await fetch(`${BASE_URL}/v1/lookup`, {
        method: 'POST',
        headers: {
            'Authorization': `Bearer ${API_KEY}`,
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({ postcode, tier })
    });

    if (!response.ok) {
        const error = await response.json();
        throw new Error(error.error?.message || 'Lookup failed');
    }

    return response.json();
}

// Usage
const result = await lookupPostcode('SW1A 1AA', 'premium');
console.log(result.data.addresses);

Node.js (Express middleware example) 

import express from 'express';

const router = express.Router();
const BASE_URL = 'https://api.domma.dev/api/address';

router.post('/validate-address', async (req, res) => {
    const { postcode } = req.body;

    try {
        const response = await fetch(`${BASE_URL}/v1/lookup`, {
            method: 'POST',
            headers: {
                'Authorization': `Bearer ${process.env.ADDRESS_API_KEY}`,
                'Content-Type': 'application/json'
            },
            body: JSON.stringify({ postcode, tier: 'premium' })
        });

        const data = await response.json();

        if (!data.success) {
            return res.status(400).json({ error: data.error.message });
        }

        res.json({
            valid: true,
            addresses: data.data.addresses,
            region: data.data.region
        });
    } catch (err) {
        res.status(500).json({ error: 'Address lookup unavailable' });
    }
});

export default router;

Python 

import os
import requests

API_KEY = os.environ.get("ADDRESS_API_KEY")
BASE_URL = "https://api.domma.dev/api/address"

def lookup_postcode(postcode: str, tier: str = "free") -> dict:
    """Look up a UK postcode via the Domma Address API."""
    response = requests.post(
        f"{BASE_URL}/v1/lookup",
        headers={
            "Authorization": f"Bearer {API_KEY}",
            "Content-Type": "application/json"
        },
        json={"postcode": postcode, "tier": tier},
        timeout=10
    )
    response.raise_for_status()
    data = response.json()

    if not data.get("success"):
        raise ValueError(data.get("error", {}).get("message", "Lookup failed"))

    return data

def get_property_history(address: str, postcode: str) -> list:
    """Retrieve transaction history for a specific address."""
    response = requests.post(
        f"{BASE_URL}/v1/property/history",
        headers={
            "Authorization": f"Bearer {API_KEY}",
            "Content-Type": "application/json"
        },
        json={"address": address, "postcode": postcode},
        timeout=10
    )
    response.raise_for_status()
    data = response.json()
    return data.get("transactions", [])


# Example usage
result = lookup_postcode("SW1A 1AA", tier="premium")
print(f"Found {result['data']['addressCount']} addresses")

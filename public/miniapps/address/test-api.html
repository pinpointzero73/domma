Test 3: Direct cURL Commands

Copy and paste these commands into your terminal:

JWT Authentication:

# 1. Register
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Test User","email":"curltest@example.com","password":"CurlPassword123!"}'

# 2. Login (save the token)
curl -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"curltest@example.com","password":"CurlPassword123!"}'

# 3. Lookup with JWT (replace YOUR_TOKEN)
curl -X POST http://localhost:3000/api/address/lookup \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"postcode":"SW1A 1AA","tier":"free"}'

API Key Authentication:

# 1. Create API key (use JWT token from login)
curl -X POST http://localhost:3000/api/address/api-keys \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"name":"My Test Key","permissions":["freeLookup","premiumLookup"]}'

# 2. Lookup with API Key (replace YOUR_API_KEY)
curl -X POST http://localhost:3000/api/address/v1/lookup \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"postcode":"SW1A 1AA","tier":"free"}'

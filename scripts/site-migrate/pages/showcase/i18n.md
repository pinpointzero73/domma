## Switch language

Each button calls `i18n.locale(code)`. That fires `change`, sets `<html lang dir>` (Arabic turns the page right to left) and re-runs `translate()` over every `data-i18n*` element on the page - the card below and the other demos follow. Polish is not added up front: the first click loads it with `i18n.load()`.

[showcase-demo id="showcase/i18n/switch-language" title="Switch language" /]

```javascript
$('#lang-switch button').on('click', async function () {
    const code = $(this).data('lang');
    if (code === 'pl') await i18n.load('pl', '/lang/{locale}.json');
    i18n.locale(code);
});
```

The card is markup only: `data-i18n` sets text, `data-i18n-html` sanitised HTML, `data-i18n-attr` attributes, each with params from `data-i18n-params`. The last line has no translation except English, so with `i18n.fallback('en')` it falls back; what the page first said is kept and shown if a key is missing everywhere.

[showcase-demo id="showcase/i18n/welcome-to-the-shop" title="Welcome to the shop" /]

```html
<h3 data-i18n="shop.title">Welcome to the shop</h3>
<p data-i18n-html="shop.signedIn" data-i18n-params='{"name": "Ann"}'></p>
<input data-i18n-attr="placeholder:shop.searchPlaceholder; title:shop.searchHint">
```

## Plurals and ordinals

A plural is an object of forms chosen by `params.count` through `Intl.PluralRules`. Polish uses one / few / many, Arabic all six, and `=0` matches exactly. Ordinals use the same object with `ordinal: true`.

[showcase-demo id="showcase/i18n/plurals-and-ordinals" title="Plurals and ordinals" /]

```javascript
i18n.add('pl', {cart: {items: {
    '=0': 'Koszyk jest pusty',
    one: '{count} przedmiot',
    few: '{count} przedmioty',
    many: '{count} przedmiotów',
    other: '{count} przedmiotu'
}}});

i18n.add('en', {race: {place: {ordinal: true, one: '{count}st', two: '{count}nd', few: '{count}rd', other: '{count}th'}}});

i18n.t('cart.items', {count: 22}, {locale: 'pl'});   // "22 przedmioty"
i18n.t('race.place', {count: 22});                   // "22nd"
```

## Placeholders and escaping

`t()` is plain text - put it in with `.text()`. `html()` keeps the message's own markup and escapes every param, so a name like `<img onerror>` arrives as text.

[showcase-demo id="showcase/i18n/placeholders-and-escaping" title="Placeholders and escaping" /]

```javascript
i18n.add('en', {greet: {hello: 'Hello, {name}!', signedIn: 'Signed in as <strong>{name}</strong>'}});

$('#out-t').text(i18n.t('greet.hello', {name}));
$('#out-html').html(i18n.html('greet.signedIn', {name}));   // <strong> kept, name escaped
```

## Formatting

Each helper is a cached Intl formatter in the current locale; pass `{locale}` in the options for another one. Switch language above to see them change.

[showcase-demo id="showcase/i18n/formatting" title="Formatting" /]

```javascript
i18n.currency(1499.5, 'EUR');                      // "€1,499.50"
i18n.currency(1499.5, 'EUR', {locale: 'de'});      // "1.499,50 €"
i18n.on('change', () => $('#price').text(i18n.currency(1499.5, 'EUR')));
```

## Usage

```javascript
const {i18n} = Domma;

// Messages: nested objects become dot keys, later add() calls merge
i18n.add('en', {demo: {greeting: 'Hello, {name}!'}});
await i18n.load('fr', '/lang/{locale}.json');   // H.get, cached, concurrent calls shared
i18n.fallback('en');

// Pick the reader's language, remember it with S
i18n.detect({storageKey: 'lang', supported: ['en', 'fr', 'de', 'ar', 'pl']});

Domma.t('demo.greeting', {name: 'Ann'});
i18n.on('change', ({locale, previous}) => console.log(previous, '->', locale));
i18n.onMissing((key, locale) => `[${key}]`);
```

```html
<h1 data-i18n="demo.title">Welcome</h1>
<p data-i18n="cart.items" data-i18n-params='{"count": 3}'></p>
<p data-i18n-html="demo.signedIn" data-i18n-params='{"name": "Ann"}'></p>
<input data-i18n-attr="placeholder:demo.searchPlaceholder; title:demo.searchHint">
```

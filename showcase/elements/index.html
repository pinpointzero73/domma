Cards

Flexible content containers with optional header, footer, and hover effects.

// Initialize card with hover effect
const card = Domma.elements.card('#my-card', {
    hover: true,           // Enable hover effects
    clickable: true,       // Make entire card clickable
    onClick: (e) => console.log('Card clicked')
});

// Or via config engine
$.setup({
    '.product-card': {
        component: 'card',
        options: { hover: true }
    }
});

Options

Option Type Default Description
hover boolean false Enable hover lift effect
clickable boolean false Make card clickable
onClick function null Click handler

Modals

Dialog windows with backdrop, keyboard support, and animations.

// Create modal instance
const modal = Domma.elements.modal('#my-modal', {
    backdrop: true,        // Show backdrop
    backdropClose: true,   // Close on backdrop click
    keyboard: true,        // Close on Escape key
    animation: 'fade',     // Animation type
    onOpen: () => console.log('Modal opened'),
    onClose: () => console.log('Modal closing'),
    onClosed: () => console.log('Modal closed')
});

// Control the modal
modal.open();
modal.close();
modal.toggle();
modal.isOpen();  // Returns boolean

// HTML structure
<div id="my-modal" class="modal">
    <div class="modal-header">
        <h5 class="modal-title">Title</h5>
        <button class="modal-close">&times;</button>
    </div>
    <div class="modal-body">Content</div>
    <div class="modal-footer">
        <button class="btn">Close</button>
    </div>
</div>

Options

Option Type Default Description
backdrop boolean true Show backdrop overlay
backdropClose boolean true Close when backdrop clicked
keyboard boolean true Close on Escape key
animation string 'fade' Animation type
onOpen function null Called when modal opens
onClose function null Called when close starts
onClosed function null Called after modal closed

Tabs

Tabbed navigation with panel switching.

// Initialize tabs
const tabs = Domma.elements.tabs('#my-tabs', {
    activeIndex: 0,        // Initially active tab
    animation: true,       // Animate panel transitions
    onChange: (index, panel) => console.log('Tab changed:', index)
});

// Control tabs programmatically
tabs.show(2);              // Show third tab
tabs.getActive();          // Get active index
tabs.next();               // Go to next tab
tabs.prev();               // Go to previous tab

// HTML structure
<div id="my-tabs" class="tabs">
    <ul class="tab-list">
        <li class="tab-item active">Tab 1</li>
        <li class="tab-item">Tab 2</li>
    </ul>
    <div class="tab-content">
        <div class="tab-panel active">Content 1</div>
        <div class="tab-panel">Content 2</div>
    </div>
</div>

Options

Option Type Default Description
activeIndex number 0 Initially active tab
animation boolean true Animate transitions
onChange function null Tab change callback

Accordion

Collapsible content sections with smooth animations.

// Initialize accordion
const accordion = Domma.elements.accordion('#my-accordion', {
    multiExpand: false,    // Allow multiple open panels
    animation: true,       // Animate open/close
    activeIndex: 0,        // Initially open panel
    onChange: (index, isOpen) => console.log(index, isOpen)
});

// Control accordion
accordion.open(1);         // Open second panel
accordion.close(0);        // Close first panel
accordion.toggle(2);       // Toggle third panel
accordion.openAll();
accordion.closeAll();

// HTML structure
<div id="my-accordion" class="accordion">
    <div class="accordion-item">
        <div class="accordion-header">
            Section 1
            <span class="accordion-icon">▼</span>
        </div>
        <div class="accordion-body">
            <div class="accordion-content">Content</div>
        </div>
    </div>
</div>

Options

Option Type Default Description
multiExpand boolean false Allow multiple panels open
animation boolean true Animate transitions
activeIndex number/array null Initially open panel(s)
onChange function null Panel change callback

What is Domma? ▼
Domma is a lightweight, zero-dependency JavaScript framework that combines jQuery-style DOM manipulation, Lodash utilities, and modern UI components in one cohesive package.
How big is the bundle? ▼
The minified bundle is approximately 125KB, which includes all namespaces: DOM, Utils, Dates, Models, Elements, and Tables.
Is it compatible with other frameworks? ▼
Yes! Domma works alongside any CSS framework like Tailwind or Bootstrap (CSS). It's framework-agnostic and can be used in any project.

Tooltips

Contextual information on hover or focus.

// Initialize tooltip
const tooltip = Domma.elements.tooltip('#my-element', {
    content: 'Tooltip text',
    position: 'top',       // top, bottom, left, right
    trigger: 'hover',      // hover, click, focus
    delay: 200,            // Show delay in ms
    animation: true
});

// Control tooltip
tooltip.show();
tooltip.hide();
tooltip.toggle();
tooltip.setContent('New text');
tooltip.destroy();

// Using data attributes
<button data-tooltip="Click me!" data-tooltip-position="bottom">
    Button
</button>

Options

Option Type Default Description
content string '' Tooltip text
position string 'top' Position: top, bottom, left, right
trigger string 'hover' Trigger: hover, click, focus
delay number 0 Show delay in ms
animation boolean true Animate show/hide

Carousel

Image and content sliders with navigation, indicators, and autoplay.

// Initialize carousel
const carousel = Domma.elements.carousel('#my-carousel', {
    autoplay: true,        // Auto-advance slides
    interval: 5000,        // Autoplay interval (ms)
    pauseOnHover: true,    // Pause on mouse hover
    loop: true,            // Loop to beginning
    animation: 'slide',    // 'slide' or 'fade'
    showArrows: true,      // Show prev/next arrows
    showIndicators: true,  // Show dot indicators
    onChange: (index) => console.log('Slide:', index)
});

// Control carousel
carousel.next();           // Go to next slide
carousel.prev();           // Go to previous slide
carousel.goTo(2);          // Go to specific slide
carousel.play();           // Start autoplay
carousel.pause();          // Pause autoplay
carousel.getIndex();       // Get current index

// HTML structure
<div id="my-carousel" class="carousel">
    <div class="carousel-track">
        <div class="carousel-slide">
            <img src="slide1.jpg" alt="Slide 1">
        </div>
        <div class="carousel-slide">
            <img src="slide2.jpg" alt="Slide 2">
        </div>
    </div>
</div>

Options

Option Type Default Description
autoplay boolean false Auto-advance slides
interval number 5000 Autoplay interval in ms
pauseOnHover boolean true Pause autoplay on hover
loop boolean true Loop back to start
animation string 'slide' Animation: 'slide' or 'fade'
showArrows boolean true Show navigation arrows
showIndicators boolean true Show dot indicators
onChange function null Slide change callback

Config Engine Integration

Initialize components declaratively using the config engine.

// Initialize multiple components at once
$.setup({
    // Cards with hover
    '.product-card': {
        component: 'card',
        options: { hover: true }
    },

    // Modal
    '#signup-modal': {
        component: 'modal',
        options: {
            backdrop: true,
            keyboard: true,
            onOpen: () => analytics.track('modal_open')
        }
    },

    // Tabs
    '#product-tabs': {
        component: 'tabs',
        options: {
            activeIndex: 0,
            onChange: (index) => loadTabContent(index)
        }
    },

    // Accordion FAQ
    '#faq-accordion': {
        component: 'accordion',
        options: { multiExpand: true }
    },

    // Tooltips on all elements with data-tooltip
    '[data-tooltip]': {
        component: 'tooltip',
        options: { position: 'top', trigger: 'hover' }
    }
});

// Components are now initialized and ready to use!

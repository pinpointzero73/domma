Usage

CSS Only

<!-- Include themes CSS --> <link rel="stylesheet" href="domma-themes.css"> <!-- Apply via class --> <body class="dm-theme-dark dm-theme-ocean">

JavaScript API

// Initialise with options Domma.theme.init({ theme: 'dark', variant: 'ocean', autoDetect: true }); // Runtime control Domma.theme.toggle(); Domma.theme.set('dark'); Domma.theme.setVariant('sunset');

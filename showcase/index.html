Domma

Dynamic Object Manipulation & Modeling API

A lightweight, zero-dependency JavaScript framework combining jQuery-style DOM manipulation, Lodash utilities, and modern components.

Zero Dependencies ~160KB Bundled ES Modules Chainable API

Quick Start

Get up and running in seconds

1. Include Domma

<script src="dist/domma.min.js"></script>

2. Use the short aliases

// DOM manipulation (jQuery-style)
$('.btn').on('click', () => alert('Clicked!'));

// Utilities (Lodash-style)
const grouped = _.groupBy(users, 'department');

// Dates (Moment-style)
const nextWeek = D().add(7, 'days').format('YYYY-MM-DD');

// Models (Reactive)
const user = M.create({ name: { type: 'string' } });
M.bind(user, 'name', '#name-input', { twoWay: true });

3. Or use the config engine for declarative setup

$.setup({
    '.card': {
        component: 'card',
        options: { hover: true }
    },
    '#submit': {
        events: {
            click: (e, $el) => $el.text('Submitted!')
        }
    }
});
